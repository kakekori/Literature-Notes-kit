# Literature-Notes-kit
Windows 文献笔记小工具，管理阅读文献时截取的片段与来源信息，写论文时快速检索定位引用内容。

- 界面：HTML + CSS
- 存储：SQLite 数据库
- 打包：aardio

 💭 将所有零散的文献摘抄、片段内容、出处、页码统一归档，一键检索；
  当然也可以当作普通的读书笔记工具来使用。

| 功     能| 说明 |  
| 记录字段 | 每条记录含：**书名/文献名、笔记内容、页码、来源、批注、图片区**|  
| 图 片 区 | 可给每条记录添加多张图片（有的文献是pdf，可以把需要的片段截图保存）|  
| 分     类| 分类可自定义命名；一条记录属于一个分类；删除分类时其记录自动变为"未分类"|  
| 文字检索 | 输入关键词，在「书名/笔记内容/页码/来源/批注」五个字段里做中文模糊搜索 |  
| 增删改查 | 新建、编辑、删除记录；按分类浏览；记录按最近更新时间排序 |  
| 快 捷 键 | `Ctrl + S` 保存当前记录 |  


🪟 运行环境
- Windows 10 / Windows 11（64位系统）
- 纯离线使用

📥 下载与安装
1. 前往项目https://github.com/kakekori/Literature-Notes-kit/releases/download/v1.0.0/_.exe
2. 第一次打开软件会自动生成本地数据库
3. 所有笔记数据由用户自行负责保存与备份
