# Literature-Notes-kit
Windows 文献笔记小工具，管理阅读文献时截取的片段与来源信息，写论文时快速检索定位引用内容。

- 界面：HTML + CSS
- 存储：SQLite 数据库
- 打包：aardio

 
💭平时看到有用的段落、经典的文献内容，随手截个图或者手抄在本子上，等到开始写论文、写综述的时候：只记得自己看过这段文献，完全忘记出自哪本书、哪个版本/截图没截到页码，标注引用时需要重新找页码。
这个工具可以：
  将所有零散的文献摘抄、片段内容、出处、页码统一归档，一键检索；
  当然也可以当作普通的读书笔记工具来使用。

💭做这个小东西只是想自己使用，所以一切都按照自己的个人喜好来的：
- 界面风格比较古早味（00年代中期流行的Aqua‑Brushed Metal）；
- 功能非常基础和简单（因为只是想记住文献来源和页码，随时取用）；
- 适用于文科学生（因为没写过文科之外的论文）；

提交之前并没有非常完整地测试过，先用看看，
如果顺手的话可能就不改了，如果有自己觉得不合适的地方会再调整。
  
 ✨ 软件功能
- 文献片段快速记录：随时摘抄文献段落、资料文本，快速保存
- 归档来源信息：可记录书名、页码、出处
- 分类管理笔记：自定义分类，不同题材分开整理
- 关键词检索：模糊搜索片段内容定位笔记
- 本地离线存储

🪟 运行环境
- Windows 10 / Windows 11（64位系统）
- 纯离线使用

📥 下载与安装
